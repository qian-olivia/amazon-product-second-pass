# amazon-product-second-pass
基于卖家精灵市场、竞品与历史数据的亚马逊产品二筛 Skill；支持资料缺失预警、降级分析和置信度标注。
# Amazon Product Second Pass

一套用于亚马逊产品第二轮筛选的 Codex Skill。

它接收卖家精灵或类似工具导出的市场分析、竞品和 ASIN 历史数据，判断一个精准产品方向是否值得进入第三轮研究。

## 核心能力

- 校验产品方向和细分市场边界
- 分析市场规模、趋势、集中度与价格结构
- 判断新品进入机会和老链接持续性
- 识别爆发性趋势、价格依赖和系统性质量风险
- 区分已验证事实、分析推断与缺失信息
- 输出明确的二筛决定和数据置信度

## 数据要求

推荐提供以下三类资料：

1. 市场分析表
2. 竞品数据表
3. ASIN 历史销量、销售额和价格表

三类资料不是强制条件。缺少文件时，Skill 会先说明：

- 缺少什么数据
- 该数据用于验证什么
- 缺失可能造成什么判断偏差
- 当前资料能否继续分析

用户确认后，Skill 可以使用现有资料完成降级分析，并降低相关结论的置信度。

## 历史数据处理

- 排除尚未结束的月份
- 区分“尚未上架”和“销量为 0”
- 按上架时长划分新品与成熟链接
- 使用市场分析表判断整体市场趋势
- 使用 ASIN 历史数据判断起量、延续、衰退和价格依赖
- 避免把当前在售 ASIN 的历史汇总误认为过去完整市场规模

## 输出结果

每个产品方向只给出一个主要决定：

- `进入第三轮`
- `条件进入第三轮`
- `观察/补数`
- `淘汰`

报告同时包含市场边界、需求规模、需求稳定性、新品进入机会、竞争与价格空间、质量风险、简化利润可行性、数据置信度及下一步最小补数需求。

## 安装

将完整目录复制到：

```text
~/.codex/skills/amazon-product-second-pass
```

目录结构：

```text
amazon-product-second-pass/
├── SKILL.md
├── agents/
│   └── openai.yaml

    └── decision-framework.md
```

## 使用方式

在 Codex 中附上已有资料并调用：

```text
$amazon-product-second-pass
```

示例：

```text
使用 $amazon-product-second-pass 分析这些市场分析、竞品和历史销量资料，判断该产品方向是否进入第三轮。
```

## 分析边界

本 Skill 用于决定是否投入第三轮研究，不代表可以直接订货。完整差评痛点、关键词策略、供应链验证、专利与合规检查以及真实 FBA 利润核算，原则上在第三轮完成。

二次更新：
优化亚马逊产品二筛分析规则：

- 新增新品分析模式，按0–30、31–60、61–90、91–180天划分上架队列。
- 区分“数据置信度”和“机会价值”，避免因历史数据不足直接否定新品。
- 将关键词数据纳入固定分析流程，区分精确购买词、场景词、宽泛词和污染词。
- 新增自然流量验证规则，优先核验3–5个相关ASIN，避免由单一头部产品推断整个市场。
- 用户提供的观点和观察先标记为待验证线索，不直接改变分析框架或结论。
- 优化市场边界判断：独立购买市场直接分析，仅在必要时扩展相邻市场。
- 将快速标品的等待成本和机会窗口纳入决策。
- 明确二筛利润测算仅用于否决检查，不作为完整利润结论。
- 要求决策发生变化时说明原依据、新证据、修正假设及变化原因。
- 新增最终报告完整性检查。
